Rolling refits are real. Selection must roll too.

A defensible production simulation must recreate what was known at every decision date, select three momentum and three breakout candidates from prior evidence only, and then preserve every position, cost, funding event and model change that would have occurred live.

Is a quarterly refit during 2026 a rolling refit?

Yes. But it is a rolling parameter update, not necessarily a rolling model-selection decision. Those must be recorded separately.

01 · SIGNAL STATE

Daily calculation

Prices update the breakout/EWMAC forecast, volatility sizing, ranks, positions and funding exposure every trading day.

02 · MODEL REFIT

Scheduled parameter update

A quarterly model may refresh scalars, correlations, weights and speed eligibility using history available before the refit. It activates next candle.

03 · ROSTER SELECTION

Which models are allowed live?

The top-three roster is a governance decision. It should change only at a predeclared promotion date using completed prior folds—not every time the leaderboard moves.

Why the current 2026 holdout is not the whole answerIt tests causal execution in one common period, but the winning model identity was selected using 2024–2025. It does not show which three models would have been chosen before 2022, 2023, 2024 or 2025, nor how roster churn would have affected a live investor.

Recommended production-like protocol

Run both nested expanding-history and fixed rolling-history reconstructions, followed by an untouched prospective shadow ledger seeded from the completed repository results.

A · HISTORICAL RECONSTRUCTION

Nested expanding walk-forward

At each 31 December cutoff, rebuild every candidate using only data then available, rank on completed inner validation folds, lock three models per family, and run them through the next year. Internal refits follow each model’s own schedule.

Outer folds: 2022, 2023, 2024, 2025 and 2026 YTD, subject to sufficient training coverage.

B · HISTORICAL RECONSTRUCTION

Nested 730-day rolling walk-forward

Repeat the same outer folds and selection process using only the trailing 730 calendar days at every selection and fitted-parameter cutoff, with a 365-day minimum. This tests whether discarding older regimes improves adaptation.

Comparison rule: identical universe, costs, funding, risk grid and outer folds.

C · LIVE REHEARSAL

Prospective shadow portfolio

Seed the six-model roster directly from the completed momentum and Carver5 result files, freeze code/config/data hashes, and emit next-open positions every day. Record the signal as emitted—not reconstructed later—and compare it with simulated fills and actual account funding where applicable.

Minimum useful period: six months; twelve months is materially better.

How to define “best three” without fooling yourself

VIEW 1 · REQUIRED

Raw top three

Rank eligible configurations by prior-fold net Sharpe, preserving the agreed tie-breaks: lower turnover, then lower gross cap, lower target volatility and configuration ID.

VIEW 2 · RECOMMENDED

Diversified top three

Start with the raw winner, then require subsequent selections to have prior-fold daily-return correlation below 0.95 and preferably differ in refit schedule or construction. Show exceptions explicitly.

VIEW 3 · DIAGNOSTIC ONLY

Today’s winners backcast

Run today’s top three across all history only as a descriptive strategy test. Label it retrospective and never mix it with the stitched production-like OOS record.

Concrete build and output contract

ENGINE

New walk-forward selector

Recreate candidate fitting and selection at each annual cutoff; store every candidate’s prior-only score and rejection reason; execute selected configurations over the next fold using existing causal portfolio, fee, slippage and funding logic.

LEDGER

Daily portfolio state

For model, family and combined levels, persist target weight, held weight, quantity, notional, forecast, risk contribution, cost, funding, return contribution, data cutoff, refit version and roster version.

REPORT

Production simulation report

Outer-fold scorecards, stitched OOS results, rolling metrics, selection stability, model-by-model composition pages, family ensembles, combined portfolio, implementation shortfall and methodological limitations.

SHADOW

Immutable forward manifests

Daily emitted signals and hashes, expected positions and funding, actual timestamps, reconstructed-versus-emitted reconciliation, and explicit alerts for missing data, changed mappings or funding coverage.

Acceptance ruleThe historical headline must be the concatenation of outer test folds only. No row may be generated by a model roster selected with data from that row or later. Today’s full-sample top-three backcast must remain a separately labelled diagnostic.

Recommendation

Build the annual nested selector and daily composition ledger first. Run the six models separately, then equal-risk family ensembles, then the 50/50 momentum–breakout portfolio. Keep annual roster decisions distinct from each model’s internal quarterly/semiannual/annual refits. Start a frozen prospective shadow roster immediately after the historical reconstruction is complete.

What this answers that the current report does notWhich models would actually have been chosen at each date, how long they survived, how their holdings evolved, whether performance persisted across folds, and what an investor would have experienced after funding and execution costs.
